# Spendlog — описание проекта

## Цель

Учебный проект для портфолио: REST API для учёта личных финансов. Задача проекта — показать полный цикл бэкенд-разработки: проектирование БД, авторизация, тесты, CI, контейнеризация, деплой.

## Что умеет (MVP)

- Регистрация и вход, JWT-авторизация
- Категории пользователя
- Операции: доходы и расходы, фильтры по типу, категории и периоду, пагинация
- Месячный лимит: потрачено, остаток, процент использования
- Отчёт по категориям за период

## Не входит в MVP

- Веб-интерфейс
- Мультивалютность
- Импорт банковских выписок
- Уведомления и фоновые задачи

## Ключевые решения

| Решение | Почему |
| --- | --- |
| Многопользовательский режим | Данные привязаны к `user_id`, чужая запись возвращает 404. Показывает работу с авторизацией и изоляцией данных |
| PostgreSQL | Точные типы (`NUMERIC`, `TIMESTAMPTZ`), конкурентная запись, востребован в вакансиях |
| SQLAlchemy 2.0 async + asyncpg | Современный стек FastAPI |
| Alembic | Версионирование схемы БД |
| Деньги в `NUMERIC(12, 2)` | `float` даёт ошибки округления |
| JWT access token | Простая авторизация без хранения сессий |
| Отдельная тестовая БД | Тесты не должны стирать рабочие данные |
| uv, ruff, pytest | Быстрый менеджер зависимостей, линтер и тесты |

## Слои приложения

- **Роуты** принимают запрос и возвращают ответ
- **Схемы (Pydantic)** проверяют входные и выходные данные
- **CRUD** выполняет запросы к БД
- **Модели (SQLAlchemy)** описывают таблицы

Точную структуру папок фиксируем по ходу работы.

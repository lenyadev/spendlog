# Spendlog

Финансовый трекер: учёт расходов и доходов, категории, месячные лимиты, отчёты.

## Цель
Личный сервис для контроля финансов и практики production-ready backend.

## Пользователь
Один пользователь: регистрируется, ведёт операции, смотрит отчёты.

## Основные функции
1. Регистрация и вход, JWT-авторизация
2. CRUD расходов и доходов
3. Категории операций
4. Месячный лимит расходов
5. Отчёт по категориям за период

## Стек
- FastAPI + Pydantic v2
- PostgreSQL + SQLAlchemy 2.0 + Alembic
- pytest
- Docker + Docker Compose
- GitHub Actions: lint + tests

## Не входит в MVP
- Telegram-бот
- Графики
- CSV-экспорт
- Redis, Celery, S3
